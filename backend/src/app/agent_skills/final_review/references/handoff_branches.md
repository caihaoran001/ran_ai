# 按需求承接的分支对照

承接消息 = 回应他的目标 + 回应他的意愿 + 问 R6。权益已经在上一条消息无条件给过，**不在这里当条件用**。

## 按下一阶段目标（R3）

| 客户想要 | 承接给什么 | 红线 |
|---|---|---|
| 继续减重／减脂 | 下一阶段的生活方式重点 + 复测节奏 | 不承诺具体斤数 |
| 维持现在的状态 | 把维持当成正式目标来安排 | **不许默认他还要继续减** |
| 先改善其他健康困扰 | 回到他在 R3C 说的那一项，先给这一项的方向 | 不把减重方案套过去 |
| 主要找日常饮品或产品 | 按日常场景说明产品差别 | 不夸功效 |
| 暂时休息／先不安排 | 一条健康收尾，说明随时可回来 | 不安排任何后续动作 |
| 还没想好 | 承接停在这里，只做收尾 | **不替他选一个** |

## 按产品服务意愿（R4）

| 客户的安排 | 承接动作 |
|---|---|
| 继续了解／使用原方案及群内服务 | 说明下一阶段怎么开始、谁跟 |
| 想看看其他适合日常的咖啡或产品 | 按日常场景给推荐 + 念已配置的会员券 |
| 先把现有产品用完再决定 | 只做用法收尾，约定他用完再来 |
| 暂时不购买，先自己调整 | 只给不需要购买的生活方式建议 |
| 暂时不需要后续安排 | 一句收尾，不推荐、不追问 |
| 还没想好 | 只做收尾，不推进 |

## 按联系偏好（R6）

R6 的选择会被系统真正执行，不是问着好看的：

| 客户选了 | 实际发生什么 |
|---|---|
| 保持正常群内提醒与反馈 | 一切照常 |
| 少打扰，有关键情况再联系 | 停掉日常追问与召回，**风险相关提醒仍会发** |
| 给我入口，我自己看 | 只给入口，不再主动问 |
| 请班主任联系我一次 | 系统给运营发一条内部提示，**只授权这一次**，不转成持续跟进 |
| 暂不接收产品推荐 | 后续承接不带产品与券，只做健康收尾 |
| 暂停主动联系 | 停掉全部主动触达 |

选了「请班主任联系我一次」时，对客户只说会安排班主任联系，**不要说"我已经通知了"**——通知是系统发的，助教说得越具体越容易和实际情况对不上。
