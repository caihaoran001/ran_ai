# 原因题（R5）的两套问法

R5 只问一套，按客户在 R4 的意愿走：

- 倾向继续（继续原方案 / 想看其他产品）→ 问 R5C
- 倾向暂缓（先用完 / 暂不购买 / 不需要后续）→ 问 R5P
- 只说"还没想好"或没答 → **两套都不问**，直接进 R6

同时选了继续和暂缓（例如"先把现有产品用完，也想看看别的"）→ 按继续问 R5C。

## R5C 继续的原因（选项由后台配置，这里只解释各项含义）

| 选项 | 客户在说什么 | 承接时怎么用 |
|---|---|---|
| 身体上的实际变化 | 他把结果归因到产品或方法 | 复述他自己说的那个变化，不加码承诺 |
| 口味喜欢 | 留存靠体验，不靠效果 | 别硬拗成"效果好"，可介绍同口味的日常选择 |
| 融入日常方便 | 看重省事 | 承接侧重"怎么继续省事"，不要加新任务 |
| 认可群里的服务 | 留存靠人 | 明确说下一阶段谁跟、怎么找到人 |
| 信任品牌 | 泛化信任 | 不要用信任换更多购买动作 |
| 想探索其他需求 | 有第二个健康诉求 | 回到 R3C 那一项，先问清方向再给建议 |
| 价格或权益合适 | 对价格敏感 | 只念已配置的权益，不许暗示"以后会更便宜" |

## R5P 暂缓的原因（这套是产品与服务改进的输入，不是挽留话术的靶子）

| 选项 | 承接的正确动作 | 绝不能做 |
|---|---|---|
| 现有产品还没用完 | 只做用法收尾，约定他用完自己来找 | 催他提前囤货 |
| 变化不明显／没达到期待 | 认下来，给一条无需购买的生活方式建议 | 说"再坚持一期才有效" |
| 口味或冲泡不合适 | 记下具体口味问题，告知会反馈 | 硬推同一款 |
| 有不舒服的地方 | **立刻停止问答，转班主任** | 自行判断是否与产品有关 |
| 价格或预算 | 不再提任何购买动作，权益该给照给 | 用折扣施压 |
| 执行太费劲 | 给一个最小可做的动作 | 再布置一整套计划 |
| 购买不方便 | 说明有哪些渠道即可 | 追问为什么不方便 |
| 群里的服务不适合我 | 认下来，问一句希望怎么改（可跳过） | 辩解或解释系统怎么运作 |
| 暂时没有这个需求 | 健康收尾，不推荐产品 | 制造需求 |
| 个人时间安排 | 健康收尾，说明随时可回来 | 追问私事 |
| 不方便说明 | 直接进 R6，不追问 | 换个说法再问一遍 |

三条通用纪律：不追问已经拒答的题；客户没回复不等于不满意；原因是拿来改产品和服务的，不是拿来反驳客户的。
