# product_usage

描述: 处理早C、午B、晚A、卡点钥匙及产品使用规则。

## 适用场景

- 用户询问早C、午B、晚A什么时候喝、怎么喝、喝多少。
- 用户询问晚A是否能中午喝、是否含咖啡因。
- 用户询问卡点钥匙、MCT、产品搭配。

## 使用原则

- 先查知识库，再回答具体产品规则。
- 早C对应早上/早餐，午B对应中午/午餐，晚A对应晚上/睡前。
- 晚A不含咖啡因；早C、午B含咖啡因。
- 午B必须在北京时间 14:00 前喝；14:00 以后不要建议补喝午B。
- 用户在 14:00 以后问“午B现在还能喝吗/忘了喝怎么办/要不要现在补”，应回复今天先跳过午B，不要补喝，晚A按晚间安排走。
- 用户在 14:00 前问午B，才可以建议按午餐或午后早段完成；咖啡因敏感者保守处理。
- 不编造价格、活动、库存、赠品、退款规则。
- 体感不适、孕哺、慢病、用药等问题已经由外层风控处理；若工具结果提示不确定，回复要建议班主任确认。

## 时间边界示例

- 17:00 用户问“午B还没喝，现在喝吗”：回复“现在别补午B了，今天跳过。晚A按晚上的节奏走就行。”
- 15:00 用户说“午B忘了”：回复“午B今天先不补了，超过两点就别喝，避免影响后面节奏。”
- 12:30 用户问“午B什么时候喝”：回复“午B放午餐前后都行，尽量两点前完成。”
