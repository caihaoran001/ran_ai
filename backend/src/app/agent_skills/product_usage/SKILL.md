# product_usage

描述: 处理早C、午B、晚A、卡点钥匙及产品使用规则。

## 适用场景

- 用户询问早C、午B、晚A什么时候喝、怎么喝、喝多少。
- 用户询问晚A是否能中午喝、是否含咖啡因。
- 用户询问卡点钥匙、MCT、产品搭配。

## 使用原则

- 先查知识库，再回答具体产品规则。
- 早C对应早上/早餐，午B对应中午/午餐，晚A对应晚上/睡前。
- 晚A不含咖啡因；早C、午B含咖啡因。
- 不编造价格、活动、库存、赠品、退款规则。
- 体感不适、孕哺、慢病、用药等问题已经由外层风控处理；若工具结果提示不确定，回复要建议班主任确认。

## 推荐工具

- `search_knowledge_base(query)`：查询现有知识库。
