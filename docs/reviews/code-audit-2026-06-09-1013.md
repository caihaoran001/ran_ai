| 缺口 | 严重度 | 阻塞性 |

| **监控告警 + 备份策略**（RDS 备份、ECS 快照、日志轮转） | P1 | 1 天 |
| **密钥管理**（`.env` 当前含真实凭据，需要 KMS 或独立凭据） | P0 | 立即 |

### 1.1 P0 — 部署前必须修复（12 项）

#### A. 安全 / 凭据

**P0-1. `.env` 含真实生产凭据且未受保护**
- 文件: `/home/chr/桌面/ran_ai/.env:18,27-28,54,58-59,62-64`

- `.gitignore` 起作用了（git 历史已确认未追踪），**但工作区仍暴露给任何能访问这台机器的进程/用户**
- **必须立即**：轮换所有 Key、改 SSH 密码

**P0-2. 后端无用户级认证体系**（仅一个共享 API Key）
- 文件: `backend/src/app/main.py:64-70`
- `X-Admin-API-Key` 单一密钥 = 一旦泄露全部沦陷

- 文件: `backend/src/app/api/routes/diagnostics.py:524-687`

#### B. Docker / 部署

**P0-5. 后端 Dockerfile.prod 单阶段 + root 运行**

**P0-8. 后端/前端容器缺 healthcheck**

**P0-9. `.gitignore` 未忽略 `.env.production` / `.env.local`**

### 1.2 P1 — 应在短期内修复（约 15 项）

#### A. 后端异常处理（系统性吞异常风险已确认）

- **缺全局异常处理器**（`main.py` 未注册 `@app.exception_handler`）
- **`document_service.py:1153` 阶段报告 LLM 失败静默吞掉**（返回空壳报告，无任何日志）
- **`channels/qiwe.py:105-106,131-132` 异常吞咽丢类型信息**（`str(exc)` 抹掉）
- **`reminder_service.py` 主循环无退避**（DB 断开会日志风暴）
- **企微/QiWe 消息处理失败无死信队列**（`wecom_service/worker.py:68-69`、`qiwe_service/aggregator.py:120-128`）
- **QiWe 渠道无重试**（`channels/qiwe.py`）

#### B. 数据库 / 性能

- **`ServiceCase` 11 个 relationship 全部 `cascade="all, delete-orphan"`**（一旦误调 `session.delete()` 会物理删全部子记录）
- **`KnowledgeFAQ` 双重级联**（ORM + FK ondelete CASCADE）
- **缺索引**：`messages.created_at`、`checkins.checkin_date`、`service_cases.deleted_at`

#### C. 部署 / 配置

- **前后端容器无日志大小限制**（长跑会撑爆磁盘）
- **`.env.production.example` 缺 `REMINDER_MESSAGE` / `INACTIVE_FOLLOWUP_MESSAGE`**
- **`config.py:25` `BACKEND_ADMIN_API_KEY` 默认值是已知占位符**（双重防护不一致）
- **CORS `allow_methods=["*"]` + `allow_headers=["*"]` + credentials=True**（过宽）
- **问卷 token 无过期机制**
- **QiWe secret 通过 Query String 传**（会进日志）
- **`QIWEI_BASE_URL` 默认 HTTP**
- **诊断端点拼暴露**（`str(exc)` 进 HTTP 响应）
- **数据库连接未配置 SSL**（RDS 跨网时明文）

#### D. 前端

- **`Dockerfile.prod` build 时未注入 `NEXT_PUBLIC_*`**（任何 `NEXT_PUBLIC_*` 变量为 build 时嵌入）
- **死代码 `FRONTEND_BASE`**（`api.ts:6-9` 无任何引用）
- **缺 `frontend/.env.local`**
