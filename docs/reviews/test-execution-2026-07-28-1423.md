## 8. 失败证据

### F-01 人工复核结论没有约束下游执行内容

样本3正确输出：

- `safety_status=manual_review`
- `manual_review_required=true`
- `weight_band=需人工复核`
- `challenge_goal=不设置`

但执行建议书仍输出：

- 早C：早餐后半份起用，无心慌可增至1份；
- 午B：午餐后、14:00前、半份起用；
- 晚A：晚餐后或睡前1–2小时、1份。

这与“人工复核用户只给安全边界和资料补充，不在复核前给具体产品方案”的目标冲突。

状态：失败  
严重度：critical

### F-02 五项打卡被标题污染并发生截断

样本1真实模型输出为单行：

`1. 每日固定打卡：1. 产品…… 2. 晚餐…… 3. 运动…… 4. 蔬菜…… 5. 精力与情绪……`

最终画像解析成：

1. `每日固定打卡`
2. 产品排班
3. 晚餐后进食
4. 运动
5. 午餐蔬菜

真正第5项“精力与情绪”被截掉。

样本3输出“1. 5项打卡：”后再列第2–6项，最终画像同样把“5项打卡”当第一题，并丢掉运动项。

状态：失败  
严重度：major

### F-03 三份真实执行建议书全部溢出到两页

Mock 样稿能控制在一页，但真实模型输出更长。三份执行建议书均为 A4 两页；样本1第二页只剩“调整和停止条件”的正文，说明版式距离一页较近，但当前结果仍不满足“一页执行纸”要求。

状态：失败  
严重度：major

### F-04 无数字目标时仍生成了固定腰围数字

样本1只选择“腰腹部维度缩减”，没有填写具体腰围数字目标。模型仍生成：

`挑战目标：腰围缩减1–3cm`

违反“用户未填写数字时不得为了分带或挑战目标编造固定数字”的规则。

状态：失败  
严重度：major

### F-05 证据数量达标，但部分证据不够科学

三份都给出了 2–3 条问卷事实，但部分“支持趋势”的内容只是当前横截面数据：

- 当前体重和腰围被写成“与下降趋势相符”；
- 当前没有运动、睡眠一般被用于支持“体重基本稳定”。

这些是用户自己的事实，但不能独立证明趋势方向。当前 Prompt 为了强制凑 2–3 条趋势证据，容易让模型把“当前状态信号”包装成“趋势证据”。

状态：部分通过  
严重度：minor

### F-06 其他内容约束偏差

- 样本1、2出现“午餐/每餐至少2拳蔬菜”，与统一的“每天至少2拳”口径冲突。
- 样本2早餐打卡同时要求“起床后1小时内完成”和“包含蛋白质+蔬菜”，一个是时间、一个是结构，属于复合判断。
- 样本3根据药物和焦虑症状写出“高血压和焦虑用药背景”，表达比原问卷事实更确定。

状态：部分失败  
严重度：minor
