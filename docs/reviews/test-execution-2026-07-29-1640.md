### 3.5 稳定性与额外观察

同一份 A 带问卷连续生成两次：

| 字段 | 是否一致 |
|---|---|
| 管理带 | 是 |
| 当前主线 | 是 |

这说明本轮新增的档位证据边界已经让档位稳定保持 A 带，但既有的重点人工复核开关仍不稳定。第二次漏标是风险更大的方向。

此外，B 样本的档位依据中出现“腰围84cm已超过女性中心型肥胖阈值”，而另一份输出又将女性切点写为85cm；不同生成结果的阈值口径自相矛盾。该项不影响本轮结构验收结论，但进一步说明当前内容仍需人工审核，且不宜直接上线。

## 4. 结论

本轮代码的结构目标已经达到：共享口径、文件分工、档位证据与执行主线分离、页面重点复核、文档版式均正常。

但真实模型没有稳定遵守最关键的数字约束：

1. A 带重复样本 **2/2 失败**；虽然未出现“0–2斤”，但出现了“1–2斤”，并重复展示用户填写的“10斤”。
2. B 带在用户未提供数字目标时自行编出多组减重数字。
3. 同一输入的重点人工复核开关仍会 `true → false`。

因此本次测试结论为：**暂不上线，先修复数字目标合同和重点复核稳定性，再做一轮小样本真实模型复测。**
