#### A带·只想调睡眠精力（175cm/63kg，safe_room 1.75kg）—— 通过

- `goal_type=general`，`user_goal=希望节律稳定和情绪更稳` —— **模型如实填写了目标类型，未脑补减重诉求**。

#### C带·明确要减10斤（165cm/78kg）—— 失败（含一项脚本设计错误）

- **脚本期望值写错**：165cm/78kg 的 `safe_room=23.55kg`，按边界本就是 D 带，不是 C 带。
  带位判定 `D带｜系统减重` **正确**，是用例设计错误，非代码缺陷。**C 带本轮实际未被覆盖。**
- 真实缺陷（见下）：D带 week5_8 写出了固定斤数；week9_12 写"15–20斤"，下界低于规定的 16 斤。

#### D带·大基数（170cm/95kg，safe_room 37.2kg）—— 失败

- 带位 `D带｜系统减重` 正确。
- 第5-8周写"累计减重6-8kg" —— 提示词明确要求 D 带此阶段**不预设固定斤数**。
- 第9-12周写"累计减重10-16kg"（＝20–32斤），规定为 16–20 斤，**严重越界**。
- 模型自行换用 kg 单位，规则以斤表述。
