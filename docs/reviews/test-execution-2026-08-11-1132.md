## 6. 运行错误与失败证据

### 6.1 26 条运行错误的共同原因

26 条全部为：

```text
IncompleteOutputException: The output is incomplete due to a max_tokens length limit.
```

这些题均已生成最终回复，其中 23 条也已获得改写查询的知识命中；错误发生在 RAGAS 结构化判官阶段。当前评测器创建判官时未把系统配置的 8000 token 上限传入 RAGAS，实际仍使用默认 1024，导致输出截断。因此本次四项 RAGAS 只有 9 条有效分母。

### 6.3 瓶盖翻车题

- 原问题：`瓶盖一盖就可以了吗`
- 上下文：晚A每次 1 大刻度、约 300ml 温水；一大刻度是瓶体三小刻度。
- 预期改写：必须明确“瓶盖用量 + 一大刻度 + 晚A”，且“一盖”是瓶盖用量，不是盖瓶动作。
- 实际改写：`晚A每次使用，瓶盖一盖就可以了吗？`
- 判断：没有改成“是否盖上瓶盖”，但仍未明确补出“一大刻度”和用量比较，改写质量不够完整。
- 实际召回：原问题召回 `瓶盖和刻度怎么换算`；改写召回晚A用量与水量，均包含“一大刻度约两瓶盖”。
- 实际回复：`晚A用瓶盖计量的话要倒两瓶盖，一盖不够。一大刻度=3小刻度≈两瓶盖，配300ml左右温水。`
- 忠诚度结论：数字、比较方向和水量均正确，没有再次说反。
- 最终状态：运行错误，原因仅为 RAGAS 判官 1024 token 截断，不能据此判定回复内容错误。
