## 发现的问题

### 高优先级

1. **SPEC-02: test_graduation_report 失败**
   - **严重程度**: 高
   - **影响**: 毕业报告生成流程可能存在问题
   - **根因**: 问卷提交返回 404，token 可能已失效
   - **建议**: 检查问卷 token 生成和验证逻辑

2. **CT-01: BMI 字段不一致**
   - **严重程度**: 高
   - **影响**: 用户画像和交付文档中的 BMI 数据不一致
   - **根因**: 文档生成过程中 BMI 字段传递可能存在问题
   - **建议**: 检查文档生成服务中的 BMI 字段映射

3. **PW-09: 诊断控制台 fetch 错误**
   - **严重程度**: 中
   - **影响**: 诊断控制台无法正常运行测试
   - **根因**: Playwright MCP 使用 Basic Auth URL 导致 fetch 失败
   - **建议**: 修复前端 API 调用中的认证方式

### 中优先级

4. **SPEC-05: Playwright 浏览器未安装**
   - **严重程度**: 中
   - **影响**: 无法执行前端 Playwright 测试
   - **建议**: 运行 `npx playwright install` 安装浏览器

5. **asyncpg 噪声**
   - **严重程度**: 低
   - **影响**: 测试输出中存在警告信息
   - **根因**: asyncpg 协议状态异常
   - **建议**: 检查数据库连接池配置

### 低优先级

6. **PW-02, PW-03, PW-07 未执行**
   - **严重程度**: 低
   - **影响**: 部分页面交互流程未验证
   - **建议**: 补充测试数据后重新执行
