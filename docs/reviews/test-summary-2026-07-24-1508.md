# 测试总结：QiWe 历史消息可用于重启对账

## 结论

通过。真实测试证明：机器人主动发送成功的文本消息会进入 `/msg/syncMsg` 历史记录，而且发送结果与历史记录中的正文、群 ID、消息唯一标识、服务端消息 ID、序号和时间戳全部一致。

本次在发送接口返回后立即发起第一次历史查询，没有人为等待。查询在 491.0ms 内返回并命中目标，因此本次观测到的同步可见上界约为 491ms；这不是平台承诺的固定 SLA，但足以证明接口具有启动恢复对账的实际价值。

## 对当前方案的意义

- 不需要每发送一条消息都查询历史。
- 服务启动时只需针对遗留 `UNKNOWN` 出站记录做有限分页对账。
- 查到与目标群、正文和发送时间窗口相符的机器人出站消息，可把 `UNKNOWN` 修正为 `SENT`。
- 查不到不能立即判定“未发送”，应保留 `UNKNOWN` 或扩大有限时间窗口，避免历史同步偶发延迟造成重复发送。
- 本轮只做接口能力验证，尚未实现自动对账代码。
