# 测试总结：QiWe 启动对账已上线并验证

## 结论

通过。生产真实验证证明：后端重启前数据库停留在 `UNKNOWN`、但企微实际已发送的消息，能够在启动后通过最多 50 条历史消息自动确认并修正为 `SENT`。

本次实现满足关键安全边界：

- 服务对外可用前冻结固定恢复 ID。
- 后台任务只处理这份固定名单，恢复后新产生的 `SENDING/UNKNOWN` 不会被扫描。
- 仅“机器人发送者、相同群、正文完全一致、3 分钟窗口、唯一且一对一”的消息可确认。
- 零匹配、多匹配、接口失败或没有起始 `seq` 时继续保持 `UNKNOWN`，绝不自动重发。
- 没有待对账消息时不调用历史接口。
- 只在启动时执行一次，不做周期扫描，不维护全局游标。
