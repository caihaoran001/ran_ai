## 结论

DeepSeek V4 Flash 能完整生成当前“画像 + 两份交付文件” package，不需要切回 Pro，也不需要拆分生成。

真正故障是 V4 默认 thinking 后，推理和最终正文共享输出预算，且模型偶尔会在 `reasoning_content` 写完整 JSON 却不输出正式 `content`。之前客户端仅给 16000 token，也没有 JSON Output、思考强度和最终 content 契约。

## 已完成的修复

- thinking 保留且明确开启。
- Flash 文档请求使用 `reasoning_effort=low`，仍有真实推理，但会及时进入最终正文。
- 文档场景独立输出上限为 `50000`，不影响聊天预算，也不代表每次固定消耗 50000。
- 启用 API JSON Output，并在系统提示词明确要求思考后将完整 JSON 输出到 `content`。
- `reasoning_content` 不作为正式文档兜底，避免把草稿、自我修正或内部判断落库给用户。
