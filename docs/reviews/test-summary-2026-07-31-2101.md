# 测试总结报告 2026-07-31 21:01

对应执行记录：`test-execution-2026-07-31-2101.md`

## 结论

本轮真实模型测试 **不通过，不建议把当前 `reasoning_effort=high` 版本部署生产**。

失败不是 JSON 格式小问题。重试机制按预期工作，也能阻止残缺文件落地；但 9 次真实文档请求只有 2 次成功，7 次均在完成 reasoning 后没有输出正式 content。4 份计划问卷只有 2 份最终生成完整 package，可靠性不足。

两个成功样本的人工内容审查也都发现实质问题：成年稳定舒适体重只采集未使用；孕期用户同时收到“不减重”和“28天减重5-6斤 / 12周累计16-20斤”，且饮食规则带有限制性减重口径。

## 主要问题（按严重程度）

1. **Critical｜孕期目标不安全且自相矛盾**

   用户明确孕20周，医生建议正常吃饭、不减重。文档一边正确提醒孕期不减重，另一边仍展示 `28天减重5-6斤` 和 `第9-12周累计16-20斤`。这说明现有“人工复核仍保留基础数字目标”的确定性契约不适用于明确禁止减重的安全场景。

2. **Major｜Flash high 正文生成可靠性不可接受**

   文档请求成功率为 `2/9`。周然、王磊各重试 3 次仍没有正式正文；失败时 completion token 远低于 50,000，因此继续加预算不能解释或解决本次失败。

3. **Major｜孕期饮食建议与安全结论冲突**

   在医生要求正常饮食的前提下，仍限制主食、水果并禁止晚餐后加餐；同时另一段又建议少食多餐。内容不适合作为正式交付。

4. **Major｜成年稳定舒适体重没有被吸收**

   陈静的 `75kg` 已正确归一化到 facts，但画像和两份用户文件都没有引用或解释，新增问卷题尚未真正产生业务价值。

5. **Minor｜个别表述质量问题**

   包括泛化描述“年龄带来的恢复能力下降”、产品剂量判断过于确信、孕期运动句残缺、孕期仍追踪腰围。

6. **Minor｜前端 smoke 预期漂移**

   `/users` 页面实际标题为“正常用户”，旧 smoke 仍期待“用户管理”，导致 Playwright `9 passed / 1 failed`。页面本身成功加载；本轮按测试边界未修改测试代码。

## 已确认有效的部分

- 9/9 文档请求都实际使用 `deepseek-v4-flash`、JSON Output、thinking enabled、`reasoning_effort=high` 和 50,000 上限。
- 内容级重试有效：能处理缺文档、真实空正文，并在最多 3 次后明确失败。
- 重试耗尽不会把 `reasoning_content` 或残缺 JSON 保存为正式文件。
- 100kg 上限已经去除：230斤正确转为115kg并进入 D 带计算。
- 明显腰高比矛盾会在模型前阻断，`ready_for_document_generation=false` 带中文原因，零模型调用。
- 每日五项是动态的：两个成功用户的题目明显不同，不是所有用户统一五项。
- 后端完整回归 `542 passed`，类型检查和 spec 发现通过。

## 流程与内容结论

- **流程通畅性：失败。** 自动重试和失败保护通畅，但真实模型最终完成率只有 2/4 问卷。
- **事实正确性：部分通过。** 体重换算、BMI、腰高比、目标带等基础事实正确；稳定舒适体重未进入内容。
- **跨文档一致性：失败。** 普通大体重样本一致，孕期安全语义与数字目标、饮食规则冲突。
- **业务合理性与安全性：失败。** 孕期样本不能作为正式用户文件。
- **动态五项：在成功样本中通过。** 2/2 成功样本题面不同；另外两份因生成失败不可评价。

## 发布建议与下一步

当前提交不要部署。建议按以下顺序修复后再做小规模真实复测：

1. 先解决 Flash high 的正式正文稳定性。不能仅继续增大 token；需要在“坚持 high”前提下重新设计生成边界或可靠降级策略。
2. 将“明确不应减重”做成结构化安全结论，使生成前目标契约输出非数字目标，并禁止后续阶段累计减重数字。
3. 在系统提示词中要求成年稳定舒适体重进入长期路径判断；缺失时由一致性闸门给出可重试原因。
4. 收紧孕期饮食、运动、产品和追踪指标口径，再复测本轮四个样本。
5. 单独修正 `/users` smoke 的现行标题断言并重跑前端基线。

本结论基于 13 次真实 Flash 调用和 2 份完整输出的逐段人工审查。模型有随机性，但连续 7/9 文档请求无正文，已经足以否定当前版本的发布稳定性；不需要用“偶发”假设掩盖失败。
