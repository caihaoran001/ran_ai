# 测试总结：六份问卷真实生成交付文档

结论：**不通过，建议先修复再部署。**

六份线上既有问卷以真实文档模型异步走了正式入营链路。五份完成了画像、诊断报告和执行建议书生成；一份 A 带样本连续三次只有模型推理、没有最终正文，因此被正式保护逻辑拦住，未产生半成品。这验证了保护有效，也暴露出约 1/6 的本轮生成可靠性风险。

已生成的五份在带位、目标、产品标准口径、每周三次运动同步以及高风险内部人工复核上均通过确定性检查。真正影响交付质量的结论有三项：

- 高风险用药样本的正文仍将“待人工确认”弱化为“暂无明确健康风险”，并出现不应有的挑战加码；应统一为“暂无已确认的健康风险；处方药与产品能否同用待人工确认”，并保持 D7 复评。
- 一份中风险文档根据缺失的化验信息作出胰岛素相关推测，超出生活方式服务边界。
- 一份常规文档的睡眠动作在两份文件中排期不一致；诊断报告平均约 2,628 字，也需要继续收紧。

独立模型审阅有一份返回“通过”但五项分数全为 1 的自相矛盾结果，已作为无效审阅记录，不用它判断产品内容。其余发现均需按源文档和问卷事实复核后修正。整个测试未写入任何用户档案、交付文件、消息或用量账本，线上健康检查正常。
