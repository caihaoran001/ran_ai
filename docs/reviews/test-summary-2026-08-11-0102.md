# RAG 固定 50 题评测集验证总结

## 结论

正式题库已从“运行时临时抽 FAQ”改为版本库内固定 50 题：25 条由权威 FAQ 改写，25 条由生产真实聊天一次性筛选并脱敏；其中 35 条应检索，15 条应跳过。同一份题库可重复运行、比较不同代码或模型，不会因生产数据变动而自动换题。

前端现在会直接展示固定集构成，并让每题对照来源、上下文、原问题、预期检索与处理方式、权威事实、实际改写、召回、回复和判定。用户可以直接看到“测了什么、应该怎样、实际怎样”。

## 本次实现的通用修复

- 取消运行时动态选题，报告的可比性由固定题库保证。
- 不再为某一个坏例列“禁止出现某句话”；改为对数字、单位、否定、比较和等价关系做通用事实一致性判定。
- 跳过检索的题也明确标注预期处理方式，区分确认收到、追问澄清、使用实时能力和接住情绪。
- Mock 报告故意保留一条瓶盖比较关系反转，页面明确显示为红色严重事实错误，证明评测链路不会用平均分遮掉关键翻车。

## 发布判断

- 本地固定题库、后端定向测试、Mock 容器、前端类型检查/生产构建和浏览器证据测试均通过。
- 这些结果证明“评测系统按固定题库跑通并可审查”，不代表当前线上 RAG 质量已达标；四项 RAGAS 的本次分数是 Mock 数据。
- 本次尚未部署 ECS，也未运行真实模型基线。后续发布后应用这同一份 50 题固定集跑首次真实基线，原样保留失败题和分数。
