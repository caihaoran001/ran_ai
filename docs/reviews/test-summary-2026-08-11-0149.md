## 已确认的正向证据

“晚A一盖是否等于一大刻度”这道关键题已经完整走过意图识别、问题改写、双路检索和回复生成：

- 原问题没有命中，改写问题命中 3 条知识。
- 实际回复正确说明“一瓶盖约 1.5 小刻度，一大刻度为 3 小刻度，约两瓶盖”。
- 通用事实一致性判官通过，没有再次出现数量关系反转。

这只能证明该单题的真实链路表现，不能代替 50 题整体基线。

## 阻塞问题

RAGAS 判官当前沿用 1024 个 token 的默认输出上限。Context Recall 和 Faithfulness 的结构化结果超过该上限后被判为不完整，导致整题成为运行错误；Context Precision、Answer Relevancy 和独立事实一致性判官可以返回。

## 下一步最小修复

只调整 RAGAS 判官自己的输出上限，不改变生产回复 Agent、评测题或预期答案。修复后按以下顺序验证：

1. 用固定数据集中的 1 题调用真实模型，确认所有指标都能完整返回。
2. 再运行固定 50 题。
3. 以第二次完整运行结果建立首个真实质量基线，并在前端展示逐题预期、实际结果和失败原因。
