## 问题分级

### 高：评测判官 token 上限未接入系统配置

- 26/50（52%）题在 RAGAS 阶段统一报 `IncompleteOutputException`。
- 实际业务回复已经生成，23 条也已经召回知识，只是评测分数没算出来。
- 这会让前端看起来像业务回复错误，实际是评测器失败，并严重缩小四项指标分母。

建议：让 RAGAS 判官显式使用系统已有的 8000 token 上限，先用 5 条曾失败样本验证不再截断，再用同一固定 50 题重跑。不要修改题目或预期。

### 高：检索覆盖与回复质量在可评分样本中明显不足

- 改写查询只在 25/35 条应检索题中命中知识。

建议：先修评测器再判断模型和检索是否需要调整；否则会把“判官没跑完”和“回复质量差”混在一起优化。
